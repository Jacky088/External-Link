# 大绵羊外链跳转插件

**插件版本**：1.0.0

**作者**：木木

## 插件简介

专为 WordPress 开发的外部链接管理插件。自动拦截文章中的外部链接，在跳转前提示用户即将离开本站，提升安全意识与体验；支持白名单设置，避免干扰信任链接。

## 核心功能

- **自动拦截外链**：非本站链接自动跳转至提示页，站内链接与白名单链接直接放行。
- **白名单**：可配置信任链接（每行一个，无需协议头），免拦截直接访问。
- **多种提示样式**：内置 8 种风格——默认（茉莉小栈）、哔哩哔哩、腾讯云社区、CSDN、知乎、通用跳转（jump）、墨星博客（moxing）、TikTok。
- **自定义 Logo**：支持上传 Logo 替换默认图标，不设置则不自动套用站点 Logo。
- **安全机制**：随机字符串 + Token 过期机制（默认 5 分钟），或 AES-256-CBC 加密（永久有效）；并支持 Referer 防护，禁止站外直接访问跳转页。
- **主题适配**：支持 7b2 主题圈子与子比（zibll）主题社区功能（可自定义内容选择器）；在子比主题下自动接管其外链重定向，避免冲突。
- **跳转页路径可自定义**：跳转页 Slug 支持后台自定义，默认 `dinterception`。
- **自动更新**：支持通过 GitHub Releases 检测并一键升级。

## 使用方法

1. 安装并激活插件（需启用固定链接）。
2. 后台进入「外链跳转插件」菜单。
3. 配置总开关、跳转页路径、白名单、提示样式、Logo、安全选项等并保存，插件即自动生效。
